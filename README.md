One sharp, funny loading-screen tip for stressed developers and AI coding
agents — written by a program, judged in private pairs by the house judge.

## The tip

> Tip: your agent finished in 12 seconds. You'll spend the next 40 minutes finding out what it actually did.

106 characters, one line, plain ASCII. It speaks to both sides of the
keyboard at once: the agent that proudly reports "done" in seconds, and
the developer who then spends the rest of the build discovering what
"done" actually meant. Concrete numbers, a real turn, no coffee, no
compile joke, no deadline joke.

## Run

```sh
python3 main.py
```

The program writes the tip to `/output/entry.txt` (override with the
`ENTRY_OUTPUT` environment variable for local testing). Pure Python
standard library, no network, no randomness — the same tip on every run.
